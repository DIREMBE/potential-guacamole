Las marcas repetidas dentro del intervalo se cuentan como una sola. Súbelo si el marcador registra varios intentos seguidos.
Cada día tiene cuatro horas: entra, sale a almorzar, regresa y se retira. La hora de almuerzo no se cuenta como trabajada. Si un día no trae las cuatro marcas, se cuenta entero y queda señalado —no se descuenta una hora que nadie marcó—. Podés corregir cualquier hora aquí antes de exportar; los totales se recalculan solos. Formato HH:MM.
